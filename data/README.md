# Dữ liệu của lab

Thư mục này **chưa có dữ liệu**: hãy tải `day09-data.zip` (đường dẫn trong `README.md` mục 3), giải nén **tại thư mục gốc của lab** (zip chứa sẵn thư mục `data/`), rồi chạy `python3 scripts/check_data.py`.

Dữ liệu được cắt từ bộ L2D-v3 của Yaak (Apache 2.0): https://huggingface.co/datasets/yaak-ai/L2D-v3
